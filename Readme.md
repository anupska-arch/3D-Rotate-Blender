# 3D Rotate for Blender

A CAD-style 3-point reference rotation add-on for Blender with visual compass HUD, native snapping markers, and screen-space magnetism.

## Features
- **3-Point Reference Rotation:** Set Base Point (pivot), Axis Direction, and Start/Target angles like Rhino or AutoCAD.
- **Native Snap Markers:** Custom 2D HUD rendering circles, triangles, squares, and perpendicular markers.
- **Screen-Space Magnetism:** Precise pixel-distance snapping for complex scenes.
- **Axis Locking:** Press `X`, `Y`, `Z` during modal steps to constrain movement.
- **Direct Value Typing:** Type numerical angles (e.g. `45`, `-90.5`) directly during the target step.

## Installation
1. Download `3d_rotate_v1.0.3.zip` from the [Releases](../../releases) section.
2. In Blender, go to **Edit > Preferences > Add-ons > Install...**
3. Select the `.zip` file and enable **3D Rotate**.

## Shortcuts
- **Launch Tool:** `Ctrl + Shift + R` (or via Right-Click Context Menu / N-Panel "Item" tab)
- **Toggle Snapping:** Hold `Ctrl`
- **Lock Axis:** `X` / `Y` / `Z`
- **Freehand Toggle:** `C`
- **Cancel:** `Right-Click` or `ESC`
